1. Scope & Objectives

Objective

To determine whether a user can log in to Demo Web Shop using valid credentials and whether the login journey rejects invalid or incomplete authentication attempts consistently.

In Scope

  • Login page access from the supplied Demo Web Shop URL.
  • Login using valid credentials.
  • Invalid email and password combinations.
  • Empty and malformed login fields.
  • Verification of the logged-in identity after successful authentication.
  • Positive, negative, and boundary-oriented login scenarios based on the supplied ticket description.

Out of Scope

  • Registration and checkout journeys, except as needed to reproduce login navigation.
  • Forgot password, social login, MFA, SSO, and account-locking behavior unless implementation evidence confirms these features.
  • Performance, load, penetration testing, or security exploitation beyond basic login validation.
  • Test-case creation and automation until human approval.
